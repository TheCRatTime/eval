# eval
**eval** - small expression parser

## Description
This is a small mathematics parser.

### Features
- **No malloc**: only stack and expression string
- **Errors**: you can see place where something went wrong
- **stb-style**: 1 define and 1 include and you have **eval()** function.

### Build
Needed:
- C Compiler
- CMake 3.10
- GNU Make

```bash
cmake -B build
cd build/
make
```
